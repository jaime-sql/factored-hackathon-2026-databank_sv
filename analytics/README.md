# Analytics

Demand, cost and dispute case-mix analysis for the hackathon. Every script reads data **read-only** and writes
aggregated CSVs to `out/` and PNG charts to `charts/` (both next to the script).

## Data it expects (not in this repo)

| Env var | Default | What it is |
|---|---|---|
| `BANK_DUCKDB_PATH` | `/workspace/hackathon-data/cache/bank.duckdb` | Local DuckDB copy of the official dataset (tables `transactions`, `customers`, `complaints`, `call_center_interactions`). Built by the Data Engineer. **Never commit it.** |
| `HACK_ML_ARTIFACTS` | `/workspace/hack-ml/artifacts` | ML artifacts dir with `val_results.json` and `thresholds.json` (only `dispute_case_mix.py` uses it). |

No `.duckdb`, `.parquet`, `.env` or other raw data files belong in this repo.

## Setup

```bash
python3.13 -m venv .venv
.venv/bin/pip install duckdb pandas matplotlib   # tested with duckdb 1.5.6, pandas 3.0.6, matplotlib 3.11.2
export BANK_DUCKDB_PATH=/path/to/bank.duckdb
export HACK_ML_ARTIFACTS=/path/to/hack-ml/artifacts   # only for dispute_case_mix.py
cd analytics
```

## Rerun

| Script | Reads | Writes |
|---|---|---|
| `python demand_metrics.py > run.log` | DuckDB | `out/tx_*.csv`, `out/cp_*.csv`, `out/res_*.csv`, `out/cost_*.csv`, `demand_metrics.sql` (every query used), `charts/01_case_mix.png`, `charts/02_complaint_trend.png`, `charts/03_resolution_days.png` |
| `python cost_projection.py` | DuckDB | `out/cost_proj_*.csv`, `charts/04_cost_projection.png` |
| `python dispute_case_mix.py` | DuckDB + ML artifacts | `out/dispute_mix_*.csv`, `charts/05_dispute_case_mix.png` |

All scripts are deterministic. To change the cost model, edit only the ASSUMPTIONS block at the top of
`cost_projection.py` (e.g. `LLM_COST_PER_CASE_USD`) and rerun. `demand_metrics.sql` is generated by
`demand_metrics.py`; don't edit it by hand.

The write-up is in [`../docs/analytics.md`](../docs/analytics.md); the dashboard spec is in
[`../docs/dashboard_spec.md`](../docs/dashboard_spec.md).
